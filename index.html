🎬 Macro Recorder v2

Rekam klik & isian di aplikasi web, ulangi sesuai kebutuhan, simpan di riwayat. Bisa juga mengisi dari data Excel.

1. Pasang (sekali saja)

Seret tombol ini ke bookmark bar: 🎬 Macro

Jika tidak bisa diseret: lalu buat bookmark baru dan tempel di kolom URL.

Jika bookmark tidak jalan di situs tujuan: , buka Console (F12) di halaman itu, tempel, Enter (di Chrome ketik dulu allow pasting).

2. Cara pakai

  1. Buka form tujuan di aplikasi, klik bookmark Macro.
  2. Klik ● Rekam, isi form seperti biasa (klik, ketik, pilih), lalu ■ Selesai rekam.
  3. Kosongkan form / buka pasien lain, klik ▶ Jalankan. Atur "Ulangi N kali" jika perlu.
  4. Beri nama lalu 💾 Simpan ke riwayat. Riwayat tersimpan di browser untuk alamat aplikasi itu; klik Muat atau ▶ untuk memakainya lagi.

Langkah berupa teks yang bisa diedit:

click | #btnTambah
set | textarea[name="catatan"] | Tidak ada keluhan
check | input[name="gangguan"][value="ya"] | true
wait | 1000

Data dari Excel (opsional): di Excel, blok sel termasuk baris judul kolom (misalnya Nama, TglHD, KtV), Ctrl+C, lalu tempel di kotak "Data Excel" pada panel. Atau pilih file CSV lewat tombol 📂. Saat merekam, isian yang sama dengan baris data pertama otomatis menjadi {{Nama}} dan seterusnya; boleh juga ditulis manual di langkah, misalnya set | #tglHd | {{TglHD}}. Saat dijalankan, makro berulang untuk setiap baris (atur "baris … s/d …" untuk sebagian). Centang "lewati yang gagal" agar baris bermasalah dicatat dan proses lanjut ke baris berikutnya. Format tanggal sebaiknya sama dengan yang dipakai aplikasi (misalnya 2026-10-12 14:07); atur kolomnya sebagai Text di Excel.

Jika ada langkah gagal, panel menampilkan nomor langkahnya. Hapus atau perbaiki baris itu. Jika klik membuat halaman dimuat ulang penuh, panel hilang (langkah draf tetap tersimpan). Nilai {{today}} diisi tanggal hari ini; {{?BB naik berapa kg}} memunculkan pertanyaan saat makro jalan, supaya isian khusus pasien (misalnya angka BB atau UF) tidak ikut tersalin. Baris baru di dalam isian ditulis \n.
