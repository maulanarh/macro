🎬 Macro Recorder (mirip iMacros)

Rekam klik & isian form di halaman web, ulangi sesuai jumlah yang diatur, atau ulangi per baris data hasil copy dari Excel/Sheet.

Batasan penting: alat ini hanya bisa merekam halaman web / aplikasi berbasis browser (misal SIMRS web). Aplikasi desktop (Windows) tidak bisa dijangkau oleh HTML; untuk itu pakai AutoHotkey atau Pulover's Macro Creator.

1. Pasang (sekali saja)

Cara A (bookmark): seret tombol hijau ini ke bookmark bar browser:

🎬 Macro

Jika tidak bisa diseret: klik , buat bookmark baru, tempel kode itu di kolom URL.

Cara B (jika situs memblokir bookmark): lalu tempel di Console (F12) pada halaman tujuan, Enter.

2. Cara pakai

  1. Buka halaman web tujuan, klik bookmark Macro → panel muncul di kanan bawah.
  2. Tempel data Excel di kotak Data Excel (blok sel termasuk baris judul, lalu Ctrl+C, Ctrl+V). Contoh judul: Nama, TglHD, KtV.
  3. Klik ● Rekam, kerjakan satu pasien seperti biasa. Nilai yang sama dengan baris data pertama otomatis menjadi {{Kolom}}.
  4. Klik ■ Selesai rekam, cek/ubah langkah, lalu ▶ Jalankan. Makro berulang untuk tiap baris data (atau sebanyak "Ulangi N kali" bila tanpa data).

Format langkah (satu per baris, bisa diedit):

click | #btnTambah
set | #nama | {{Nama}}
set | #tglHd | {{TglHD}}
set | #adekuasi | {{KtV}}
wait | 1000
click | #btnSimpan

Placeholder khusus: {{no}} nomor urut, {{today}} tanggal hari ini. Untuk isian tipe tanggal, format 15/10/2026 otomatis diubah ke format yang diterima browser. Langkah & data tersimpan otomatis di browser per situs.

Catatan: jika klik membuat halaman dimuat ulang penuh, panel hilang (aktifkan lagi). Aplikasi satu halaman (SPA) aman.
